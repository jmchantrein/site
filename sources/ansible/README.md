# Sources — TP Ansible

TP de Jean-Mathieu Chantrein (Université d'Angers). `TP/notes.md` est la
source de référence : les corrections y sont balisées entre
`(DEBUT CORRECTION)` / `(FIN CORRECTION)` (commentaires Markdown) et
`TP/sans_les_corrections.md` en est la version générée pour les
étudiants (voir la commande `sed` en tête de `notes.md`).

Le TP source est lié à l'infrastructure universitaire (serveur
« starwars », VPS KVM, nœud LXC, loginENT). L'intégration au site le
généralise sur un labo Docker reproductible, avec encarts « Étudiants
d'Angers » pour la variante infra : voir
`../../docs/plan-integration-outils-admin-sys.md`.
