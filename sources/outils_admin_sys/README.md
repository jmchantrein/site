# Sources — « Introduction aux outils d'administration systèmes »

Deux présentations Beamer (parties 1 et 2) de Jean-Mathieu Chantrein
(Université d'Angers / LERIA), licence CC BY-NC-SA 3.0 (déclarée via
`doclicense` dans le préambule LaTeX). Le répertoire `code/` (identique
dans les deux parties) contient les scripts Bash affichés par
`\lstinputlisting`.

Plan source (27 h) : partie 1 — Vim (2 h), Markdown (2 h), Bash/sed/awk
(5 h), SSH (2 h), WireGuard (2 h) ; partie 2 — Git (3 h), YAML et JSON
(2 h, délégué au dépôt `yaml_et_json`), Ansible (9 h, délégué au dossier
`../ansible/`).

Conversion en cours de cadrage : voir
`../../docs/plan-integration-outils-admin-sys.md`.

N. B. : le tutoriel sed/awk référencé par la partie 1
(`softsam/sed-awk-tutoriel`, forké sous `jmchantrein/sed-awk-tutoriel`)
n'est **pas** déposé ici : le dépôt d'origine ne porte aucune licence
(tous droits réservés par défaut). Les exercices sed/awk du site seront
réécrits (énoncés, données et solutions originaux).
