Nouvelle thématique sur ce site : le **développement**, par la porte des **interfaces graphiques**. Ce cours reprend et modernise le cours Qt de Vincent Barichard (LERIA, Université d'Angers) : le fond est le sien, la cible est **Qt 6** — et, fidèle aux habitudes du site, chaque exemple montré est un fichier réel, **compilé et exécuté par la CI**. Objectifs de ce module :

- savoir ce qu'est Qt, d'où il vient, sous quelles licences il vit ;
- mesurer ce qu'il couvre (bien plus que la GUI) ;
- compiler et exécuter votre premier programme, avec CMake.

## Qu'est-ce que Qt ?

**Qt** (prononcé *cute*) est un **framework** C++ : un ensemble de bibliothèques *et* une manière de structurer son application — entièrement orienté objet, dont le module historique QtWidgets permet de développer des interfaces graphiques **natives** (l'application a l'apparence de son système d'accueil). Son développement débute en 1994 chez Trolltech ; il est aujourd'hui porté par **The Qt Company** et une communauté (le *Qt Project*), après un passage chez Nokia (2008-2012) puis Digia — l'histoire mouvementée n'a jamais interrompu le développement.

La **portabilité** est l'argument fondateur : le même code se recompile pour Linux/X11/Wayland, Windows, macOS, Android, iOS et l'embarqué. KDE (l'environnement de bureau), VLC, OBS Studio ou le logiciel embarqué de bien des véhicules sont écrits avec Qt. Des *bindings* existent pour d'autres langages — Python en tête (PySide, le binding officiel).

<Note type="info" title="Licences : lisez avant d'entreprendre">
  Qt est disponible sous **licences libres** (LGPL v3 pour l'essentiel des modules, GPL pour certains) et sous **licence commerciale**. Pour un TP, un logiciel libre ou un usage interne, la LGPL couvre tout ; c'est au moment de distribuer un logiciel propriétaire *statiquement lié* que la question se pose sérieusement. Réflexe professionnel désormais familier : la licence se lit **avant** d'écrire la première ligne.
</Note>

## Ce que Qt sait faire

La GUI est l'arbre qui cache la forêt. Qt fournit aussi : les **conteneurs et chaînes** (QString est nativement Unicode), les fichiers et flux, le **réseau** (HTTP, TCP/UDP, WebSockets), les **bases de données** (PostgreSQL, SQLite, MySQL…), le XML et le JSON, les threads, la 3D, l'**internationalisation** complète (Qt Linguist) — le tout portable. Une application Qt peut n'avoir aucune fenêtre : la moitié des exemples de ce cours sont des programmes console.

Deux mécanismes singularisent Qt dans le paysage C++ :

- le **système de méta-objets** (et son compilateur **moc**) : il donne aux objets Qt l'introspection, les propriétés et les **signaux et slots** — le mécanisme de communication qui remplace les *callbacks*, au cœur du [module 2](../qt-objets-signaux/) ;
- un **outillage** complet : Designer (dessiner les interfaces), Linguist (traduire), et l'intégration **CMake** — le [module 4](../qt-outils/) les passe en revue.

<Note type="warning" title="qmake, .pro : l'ancien monde">
  Le cours d'origine (ère Qt 4) construisait avec **qmake** et ses fichiers `.pro` (`SOURCES = hello.cpp`, `CONFIG += qt warn_on release`…). qmake existe encore, et vous croiserez des `.pro` dans de nombreux projets — mais depuis Qt 6, **CMake est l'outil officiel** : c'est lui que la documentation, les IDE et ce cours utilisent. Autre trace d'époque : `#include <Qt/QtGui>` puis « l'include qui inclut tout » — aujourd'hui on inclut **une classe = un en-tête** (`#include <QLabel>`), et les widgets vivent dans le module **QtWidgets** (séparé de QtGui depuis Qt 5).
</Note>

## Récapitulatif

- **Qt** : framework C++ orienté objet, portable (desktop, mobile, embarqué), licences LGPL/GPL/commerciale — à lire avant d'entreprendre.
- Bien plus que la GUI : conteneurs, réseau, SQL, i18n… — et deux singularités : le **système de méta-objets** (signaux/slots, moc) et l'outillage.
- Le squelette : une **QApplication** unique, des widgets (le top-level **sur la pile**), et `app.exec()` — la boucle d'évènements.
- **CMake** est le système de construction de Qt 6 (qmake/`.pro` : l'ancien monde, encore visible dans la nature).
- Les exemples du cours sont compilés **et exécutés** par la CI (`--smoke`), et les captures régénérées depuis le code (`--capture`).
